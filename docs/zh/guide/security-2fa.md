# 安全 - 双因素认证 (2FA)

双因素认证（Two-Factor Authentication, 2FA）为您的 gocron 账户提供额外的安全保护层。

## 什么是双因素认证

双因素认证是一种安全机制，要求用户在登录时提供两种不同的身份验证因素：
1. **您知道的东西**：用户名和密码
2. **您拥有的东西**：手机上的身份验证器应用生成的动态验证码

## 启用 2FA

### 步骤 1：登录账户

使用您的用户名和密码登录 gocron 管理界面。

### 步骤 2：进入安全设置

1. 点击右上角的用户菜单
2. 选择"安全设置"或"账户设置"
3. 找到"双因素认证"选项

### 步骤 3：扫描二维码

1. 在手机上安装身份验证器应用（推荐使用 Google Authenticator 或 Microsoft Authenticator）
2. 使用身份验证器应用扫描页面上显示的二维码
3. 或者手动输入密钥

### 步骤 4：验证并启用

1. 在身份验证器应用中会显示一个 6 位数字的验证码
2. 在 gocron 页面中输入该验证码
3. 点击"启用"按钮

::: tip 提示
请妥善保存恢复代码，以防丢失手机时无法登录
:::

## 使用 2FA 登录

启用 2FA 后，每次登录时需要：

1. 输入用户名和密码
2. 打开身份验证器应用
3. 输入应用显示的 6 位验证码
4. 点击登录

## 禁用 2FA

如果需要禁用双因素认证：

1. 登录 gocron 管理界面
2. 进入安全设置
3. 找到"双因素认证"选项
4. 点击"禁用"按钮
5. 输入当前的验证码以确认操作

## 恢复访问

如果您丢失了手机或无法访问身份验证器应用：

1. 使用之前保存的恢复代码登录
2. 或由管理员在命令行重置账户 —— 参见
   [密码重置 (CLI)](./password-reset)，并使用 `--disable-2fa` 选项

## 最佳实践

- **备份恢复代码**：将恢复代码保存在安全的地方
- **使用可靠的验证器**：推荐使用 Google Authenticator 或 Microsoft Authenticator
- **定期检查**：定期检查 2FA 设置是否正常工作
- **多设备备份**：可以在多个设备上添加同一个账户
